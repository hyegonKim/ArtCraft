# Adobe Creative Cloud Desktop (`KCCC v6.9.1`) Full Catalog REA Analysis & ArtCraft Suite Integration

## 1. Overview

Using `rea@6.10.1` (`inspect-pe-imports`, `inspect-pe-certificates`, `inspect-binary-hardening`, `analyze-javascript-application`) and direct binary/XML/SQLite inspection of the shipped **Adobe Creative Cloud Desktop (`v6.9.1`)** installation (`Creative Cloud.exe`, `CCXProcess.exe`, `AppsPanelBL.dll`, `FontsPanelBL.dll`, `FilesPanelBL.dll`, `CCLibrary.exe`, `C:\ProgramData\Adobe\OOBE\ffc`, `pim.db`, `ANEData.db`, `filesync.db`, `pdb.db`) alongside installed Adobe CC 2027 desktop binaries (`Photoshop 28.0`, `Camera Raw 19.0`, `Illustrator 31.0`, `Premiere Pro 27.0`, `Media Encoder 27.0`, `After Effects 27.0`, `InDesign 22.0`, `InCopy 22.0`, `Audition 27.0`, `Animate 27.0.1`, `Lightroom CC 9.6`, `Lightroom Classic 16.0.1`, `Acrobat DC 26.2`, `Dreamweaver 21.8.1`), all Creative Cloud Desktop applications, companion web/mobile workflows, and shared platform services were mapped and integrated across **18 ArtCraft workspaces**.
